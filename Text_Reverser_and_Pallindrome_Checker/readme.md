# String Tool

Simple Rust program for text operations.

## Description
Reverse strings or check if they're palindromes.

## Features
- Reverse text
- Check palindrome
- Simple menu

## Usage

```bash
cargo run
```

**Reverse text:**
```
enter text: hello
enter options (a or b): a
reversed text is olleh
```

**Check palindrome:**
```
enter text: racecar  
enter options (a or b): b
the text racecar is palindrome
```

## Build
```bash
cargo build --release
```
