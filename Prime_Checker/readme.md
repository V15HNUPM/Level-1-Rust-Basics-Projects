# Prime Checker

Check if a number is prime using Rust.

## Description
Simple program that determines if a given number is prime using efficient mathematical checks.

## Features
- Prime number verification
- Efficient up to square root checking
- Handles edge cases (0, 1, 2)

## Usage

```bash
cargo run
```

**Examples:**
```
enter a number: 17
its a prime number
```

```
enter a number: 15  
its not a prime number
```

## Build
```bash
cargo build --release
```
