# Factorial Calculator

Calculate factorials in Rust.

## Description
Computes the factorial of a given number using iterative multiplication.

## Features
- Factorial calculation
- Handles base cases (0, 1)
- Efficient iterative approach

## Usage

```bash
cargo run
```

**Examples:**
```
enter which numbers factorial you want to generate: 5
factorial is 120
```

```
enter which numbers factorial you want to generate: 0
factorial is 1
```

## Build
```bash
cargo build --release
```
