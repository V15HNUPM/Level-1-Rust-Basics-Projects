# Fibonacci Generator

Generate Fibonacci sequences in Rust.

## Description
Creates Fibonacci sequences up to a specified length using vector storage.

## Features
- Generate Fibonacci numbers
- Handles edge cases (0, 1, 2)
- Efficient sequence building

## Usage

```bash
cargo run
```

**Examples:**
```
Enter the number of Fibonacci numbers you want to generate: 5
Fibonacci sequence: [0, 1, 1, 2, 3]
```

```
Enter the number of Fibonacci numbers you want to generate: 8
Fibonacci sequence: [0, 1, 1, 2, 3, 5, 8, 13]
```

## Build
```bash
cargo build --release
```
